# App Development Research #

## React native ##

*  Recommended by software department of Recycle NXT
*  JavaScript Library
*  Can be used for Android, IOS and others
*  High Level Language good for Front End dev
*  Used by facebook, discord, …
*  https://github.com/facebook/react-native for more info
*  Testing possible
*  https://reactnative.dev/docs/getting-started to learn the basics of the language
*  Better to use with Expo (a framework)
*  Potentially using for App Development in the project depending on end product of back end development

## App Requirements ##
* Make sure app is tested with no bugs
* make sure all app information is accurate
* Provide details regarding the non obvious application features
* Make sure content of application do not offend anyone
* NO COPYRIGHTS
* App must include :
* - Ability to block user
  - Mechanism to report user
  - method to filter offensive content
* This project is not targeted at kids
* Ensure user data is secured
* A way to contact the devs is needed
* Unique application name!!
* Apps must only use public APIs and is functional in IPv6-only networks
* Apps cannot read or write data outside itself
* Most of the requirements is up to the person who submits the application
