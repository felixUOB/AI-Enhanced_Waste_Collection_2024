# Project Proposal

In this meeting we hope to cover the aim of the project in your eyes and the best way of developing it. 
This proposal aims to tackle **Six** main components: 
  - Route Planning and Variables
  - User Interface
  - Data Reports
  - Optimizations
  - Schedualing
  - General Admin
Each section will have what we believe you would like from this product with some questions we have raised about implementation.

## Preparatory Route Planning and Variables

In this section we are of the understanding that you would like a personalised route per collection truck for a certain area that
is realtime and updates as circumstances change which takes into account Behavioural Patterns, Load Capacity and Environmental Impacts.

Questions
 - Are there any other variables you would like to take into account in preparatory route planning
 - How large is the scope of the area to be covered?
 - How many routes will need to be calculated daily?


## User Interface
For UI we belive that you would like a relativly simple to operate application in which you are able to view routes, route
metrics (speed/time etc.), environmental impact reports and recive notifications of different types handsfree and simplified
for ease of use whilst driving.
A User account could be used to access the app to differentiate driver routes and allow varying levels of access to statistical
reports if data is sensitive and needs to be restricted for some users.

Questions
 - Which platform would suit the application best?

## Data Reports

For statistical analysis we belive you want in-depth analysis of relevant ecological metrics displayed in a simplified manner.

Questions

## Optimizations

To optimize routes in realtime, metrics such as traffic and weather could be used as to recude overall drive time.

## Scheduling

We belive it may be benificial to implement an aspect of variable schedualing into the application. This allows for collection days to 
added and removed from the collection cycle depending on collected data, (i.e adding an extra collection day around holidays as 
waste typically increases). However if collection days are set then this is less relevent.
