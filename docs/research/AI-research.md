# Data analysis libraries

## NumPy
  * Widely used for linear algebra and statistcal analysis
  * Adds support for large multi-dimensional arrays and matrices

## Pandas
  * Ideal for data cleaning, exploration, and analysis
  * Built upon NumPy
  * Offers data structures for manipulating numerical tables
  * Has been criticised for its inefficiency - it can require 5 to 10 times as much memory as the size of the underlying data

# Deep learning frameworks

Neural networks could be used to predict number of trucks needed and optimal scheduling based on previously gathered data

## PyTorch
  * Open-source deep learning framework developed by Facebook
  * Most widely used Python library for ML
  * Provides two high-level features:
    1. Tensor computing (like NumPy)
    2. Building deep neural networks

## TensorFlow
  * Open-source library developed by Google
  * 2nd most commonly used Python ML library after PyTorch
  * Used by Coca-Cola to optimise production line model
  * Hard for beginners to learn
  * Has a particular focus on training and inference of deep neural networks
