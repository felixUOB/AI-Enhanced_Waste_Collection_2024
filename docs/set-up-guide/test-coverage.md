## Test Coverage Guide

# Flutter

# Generate `coverage/lcov.info` file
Navigate to the frondend directories 
cd ewc_frontend/
flutter test --coverage
# Generate HTML report
# Note: on macOS you need to have lcov installed on your system (`brew install lcov`) to use this:
genhtml coverage/lcov.info -o coverage/html
# Open the report
open coverage/html/index.html


# Install the covergutter extension to be able to see the test coverage in vscode
Name: Coverage Gutters
Id: ryanluker.vscode-coverage-gutters
Description: Display test coverage generated by lcov or xml - works with many languages
Version: 2.13.0
Publisher: ryanluker
VS Marketplace Link: https://marketplace.visualstudio.com/items?itemName=ryanluker.vscode-coverage-gutters
then it will use the coverage files to show the code coverage in watch icon on bottom of screen.
