# Data Collection Overview # 

 

a. Sources of Data: 

• Client based Data: Initial datasets include waste collection records, such as pickup schedules and the volume of plastic waste collected from households, along with user interactions via the app. 

• Physical Collection Points: Collection points are set up at universities, apartments, and other locations to gather data on deposited waste. 

• Online Collection Points: Users can report their waste disposal needs through the app, helping to understand waste generation patterns and scheduling. 

 

Initial suggestion: Mock data (mostly.ai, mockaroo.com, workik.com, tonic.ai) 

 

b. Data Sensitivity: 

• Sensitive Data: It’s essential to anonymize and protect user information, such as pickup addresses and recycling history. 

• Public Data: Information on collection point locations, city routes, and waste types is not sensitive and can be shared freely. 

 

APIs and Cost Considerations: 

Several APIs will be integrated, including: 

 

Google Maps API for route planning and real-time tracking. 

Geolocation APIs for tracking vehicles in real-time. 

Data aggregation APIs to manage data from collection points and online submissions. 

 

Cost Considerations: While some APIs, like Google Maps, offer free usage limits, there may be subscription fees as usage increases, particularly for route tracking. 

 

Application Platform Development: 

• Cross-Platform Development: The application should be available on both iOS and Android.

Projected Scale of the Application: 

a. Route Generation: 

• Initial Phase: An expectation of generating 25-50 routes per day during the initial rollout, focusing on select areas in urban Chennai. 

• Scaling Phase: Aiming to increase to 100-150 routes per day as the system expands, broadening coverage as the app and collection points gain traction. 

 

b. Coverage Area: 

• Initial Rollout: The service will cover an area of approximately 300-400 square kilometers, starting in Chennai. 

• Expansion Plan: Future growth could extend coverage to around 1,500 square kilometers, including nearby cities.
